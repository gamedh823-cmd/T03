# WONWON STUDIO

## Layer-based Social Image Editor

WONWON STUDIO는 이미지와 문구를 조합하여 SNS 콘텐츠를 제작할 수 있는 웹 기반 이미지 편집 도구입니다.

사용자는 캔버스 환경에서 이미지, 텍스트, 이모지, 카오모지 등의 요소를 추가하고 각각의 요소를 독립적인 레이어로 관리할 수 있습니다.

본 프로젝트는 복잡한 디자인 프로그램 없이도 사용자가 직관적으로 이미지 콘텐츠를 제작할 수 있도록 레이어 기반 편집 방식을 적용하였습니다.

## Project Overview

SNS 콘텐츠 제작 과정에서는 이미지, 텍스트, 스티커 등 다양한 시각 요소를 조합해야 합니다.

하지만 기존 이미지 편집 프로그램은 전문적인 기능이 많은 만큼 초보 사용자가 접근하기 어렵다는 문제가 있습니다.

WONWON STUDIO는 이러한 문제를 해결하기 위해 웹 브라우저 환경에서 동작하는 간단한 레이어 기반 이미지 편집기를 구현하였습니다.

사용자는 하나의 캔버스 안에서 다양한 요소를 추가하고 자유롭게 배치할 수 있으며, 추가된 요소들은 각각 독립적인 레이어로 관리되어 수정과 편집이 가능합니다.

## Main Features

### Layer-based Editing

모든 콘텐츠 요소를 독립적인 레이어로 관리합니다.

지원 기능:

- 이미지 레이어 생성
- 텍스트 레이어 생성
- 이모지 및 카오모지 레이어 생성
- 레이어 선택
- 레이어 이동
- 레이어 순서 변경
- 레이어 삭제

---

### Image Editing

이미지 요소를 활용하여 콘텐츠를 제작할 수 있습니다.

지원 기능:

- 배경 이미지 등록
- 사용자 이미지 추가
- 이미지 위치 이동
- 이미지 크기 조절
- 이미지 레이어 관리

---

### Text Editing

텍스트 요소를 추가하여 이미지 콘텐츠에 필요한 문구를 작성할 수 있습니다.

지원 기능:

- 문구 레이어 추가
- 텍스트 내용 수정
- 글자 크기 변경
- 색상 변경
- 텍스트 스타일 적용

---

### Emoji & Kaomoji Sticker

SNS 콘텐츠 제작에 활용할 수 있는 스티커 기능을 제공합니다.

지원 기능:

- 이모지 추가
- 카오모지 추가
- 스티커 이동
- 스티커 크기 조절
- 스티커 레이어 관리

---

### Export & Project Management

제작한 결과물을 저장하고 관리할 수 있습니다.

지원 기능:

- PNG 이미지 저장
- 프로젝트 데이터 내보내기
- 프로젝트 데이터 불러오기
- 작업 상태 복원
