# WONWON STUDIO

## Layer-based Social Image Editor

WONWON STUDIO는 사용자가 별도의 전문 디자인 프로그램 없이도 웹 환경에서 SNS 콘텐츠를 제작할 수 있도록 구현한 레이어 기반 이미지 편집 서비스입니다.

최근 SNS 콘텐츠 제작 과정에서는 이미지, 텍스트, 스티커 등 다양한 시각 요소를 조합해야 하지만, 기존 디자인 도구는 기능이 복잡하고 학습 비용이 높다는 한계가 있습니다. WONWON STUDIO는 이러한 문제를 해결하기 위해 직관적인 인터페이스와 간단한 조작 방식으로 누구나 쉽게 콘텐츠를 제작할 수 있는 웹 기반 편집 환경을 제공하는 것을 목표로 개발되었습니다.

사용자는 하나의 캔버스 위에서 배경 이미지, 사진, 문구, 이모지, 카오모지 등의 요소를 각각 독립적인 레이어로 추가하고 관리할 수 있습니다. 추가된 요소들은 개별적으로 이동, 크기 조절, 수정 및 삭제가 가능하며, 레이어 구조를 기반으로 자유로운 콘텐츠 편집이 가능합니다.

# Project Background

SNS 환경에서는 카드뉴스, 홍보 이미지, 이벤트 이미지 등 다양한 형태의 시각 콘텐츠 제작 수요가 증가하고 있습니다.

하지만 기존 이미지 편집 프로그램은 전문적인 기능을 제공하는 대신 처음 사용하는 사용자에게 높은 진입 장벽을 가지고 있습니다.

WONWON STUDIO는 복잡한 디자인 툴의 기능을 모두 제공하기보다, SNS 콘텐츠 제작에 필요한 핵심 기능을 중심으로 구성하여 사용자가 빠르고 직관적으로 결과물을 제작할 수 있도록 설계하였습니다.

특히 레이어 기반 편집 방식을 적용하여 각각의 콘텐츠 요소를 독립적으로 관리할 수 있도록 하였으며, 사용자가 원하는 구성으로 자유롭게 배치하고 수정할 수 있도록 구현하였습니다.

# Main Features

## 1. Layer-based Canvas Editing

WONWON STUDIO의 핵심 기능은 캔버스 기반 레이어 편집 시스템입니다.

사용자가 추가하는 모든 요소는 개별 레이어로 관리되며, 각 레이어는 독립적으로 선택하고 수정할 수 있습니다.

주요 기능:

- 이미지, 텍스트, 스티커 레이어 생성
- 선택한 레이어 이동
- 레이어 순서 변경
- 선택 레이어 삭제
- 레이어별 속성 수정

이를 통해 여러 요소가 포함된 콘텐츠에서도 원하는 요소만 선택적으로 편집할 수 있습니다.

---

## 2. Image Editing

이미지 요소를 활용하여 다양한 형태의 콘텐츠 제작이 가능합니다.

지원 기능:

- 사용자 이미지 업로드
- 배경 이미지 설정
- 이미지 위치 이동
- 이미지 크기 조절
- 이미지 레이어 관리

추가된 이미지는 캔버스 내에서 자유롭게 배치할 수 있으며, 다른 콘텐츠 요소와 함께 조합하여 하나의 디자인 결과물을 제작할 수 있습니다.

---

## 3. Text Editing

텍스트 레이어를 활용하여 콘텐츠에 필요한 문구를 추가하고 수정할 수 있습니다.

지원 기능:

- 텍스트 레이어 추가
- 문구 내용 수정
- 글자 크기 조절
- 텍스트 색상 변경
- 텍스트 스타일 적용

텍스트 역시 독립적인 레이어로 관리되어 이미지 요소와 별도로 편집 가능합니다.

---

## 4. Emoji & Kaomoji Sticker

SNS 콘텐츠 제작에 활용할 수 있도록 다양한 스티커 요소를 제공합니다.

지원 기능:

- 이모지 스티커 추가
- 카오모지 추가
- 스티커 위치 이동
- 스티커 크기 조절
- 스티커 레이어 관리

사용자는 제공되는 요소를 활용하여 콘텐츠에 개성을 추가할 수 있습니다.

---

## 5. Export & Project Management

제작한 콘텐츠를 저장하고 관리할 수 있도록 결과물 저장 기능을 제공합니다.

지원 기능:

- PNG 이미지 다운로드
- 프로젝트 데이터 내보내기
- 프로젝트 데이터 불러오기
- 작업 상태 복원

이를 통해 제작한 결과물을 실제 SNS 콘텐츠 형태로 활용할 수 있습니다.
